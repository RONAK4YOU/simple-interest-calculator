## Fork and merge questions

The assignment's fork, pull request, and merge are account-specific actions. Save the actual commands and terminal output in separate files named `forked-repo.txt`, `merge-branches.txt`, `bug-fix-revert.txt`, and `github-branches.txt`. Include commands such as `git checkout main` and `git merge bug-fix-typo` where the assignment asks. Use your real repository and branch names. A local merge is not proof of a GitHub fork or pull request.

For the assignment's named upstream, follow its instructions and fork it from GitHub while signed in. The project in this folder is your calculator project; it does not itself establish that fork relationship.
