# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Open an issue describing the bug or proposed change. For small documentation fixes, an issue is optional.
2. Fork the repository and create a focused branch from `main`.
3. Make the change and check the script with a normal example and invalid input.
4. Open a pull request against `main`. Explain what changed and include the commands or examples you used to check it.
5. Be responsive to review feedback and keep discussion respectful.

Please do not include secrets, personal financial data, or unrelated changes. By contributing, you agree that your contributions are provided under the project's Apache License 2.0.
